How Human Pose Estimation Works

Pose estimation turns raw visual input into a structured description of the human body, making it possible to describe movement through landmarks and skeletal relationships instead of relying only on the raw pixels in an image.

What Is Human Pose Estimation?

Human pose estimation (HPE) is a computer vision task for inferring the position and configuration of the human body from images or video. Rather than treating a person as one single object, pose-estimation systems identify specific anatomical points—often called keypoints or landmarks—such as the shoulders, elbows, hips, knees, and ankles.[1]

These landmarks provide a simplified representation of a person’s pose. When connected according to the body’s structure, they can form a skeletal model that can be analyzed computationally. Pose-estimation systems may describe landmarks in 2D image coordinates or estimate their positions in 3D space.

For exercise analysis, this representation is useful because movement can be studied by tracking how landmarks change over time. Instead of analyzing every pixel in a video directly, an application can use the relevant joints to study movement patterns, joint angles, and exercise repetitions.

Keypoints and the Human Skeleton

Pose-estimation systems represent the body using anatomical keypoints such as the shoulders, elbows, wrists, hips, knees, and ankles. These landmarks encode the positions of important joints and can be tracked over time to describe movement.

When related keypoints are connected, the result is a skeletal representation. For example, the hip → knee → ankle sequence defines a lower-limb segment that can be analyzed to infer limb orientation and movement. These three points can later be used to calculate knee angle during exercise, which helps us understand movement phases in activities such as squats.

2D vs. 3D Pose Estimation

2D

2D pose estimation predicts landmark locations in image coordinates, typically as x and y positions in the image plane.[1]

This representation works well when the camera view is clear and the motion is easy to see. However, it does not capture depth, so two poses with different spatial arrangements can look similar when projected onto the image plane.

3D

3D pose estimation extends the problem by estimating the spatial position of landmarks in three-dimensional space, often including depth information.[1]

This richer representation gives a more complete view of movement in space, but it also adds complexity because the model must estimate depth and account for perspective.

From an Image to a Pose

The conceptual pipeline begins with a camera image or frame. A pose-estimation system first identifies the person in the scene and then estimates the positions of individual body landmarks. This is different from ordinary object detection, which may return only a bounding box around the person.

A pose-estimation model outputs the locations of keypoints such as the shoulders, elbows, wrists, hips, knees, and ankles. These landmarks are then connected into a skeletal representation that describes the pose more precisely than a simple box or object label.

From Images to Real-Time Video

Video is a sequence of frames, and real-time pose systems repeatedly estimate or track landmarks as each new frame arrives. Because consecutive frames are temporally related, a system can often use previous detections or motion estimates to reduce the need for a complete detection pass on every frame.

This temporal continuity is important for exercise analysis, where movement evolves gradually over time and the same body landmarks should remain associated across adjacent frames.

Why This Matters for Exercise Analysis

Pose landmarks become useful for exercise analysis when their positions are measured over time. For example, during a squat, the hip, knee, and ankle landmarks can be used to calculate the knee angle and track how the joint changes through the movement cycle.

Changes in joint angles can help identify movement phases, estimate repetition counts, or assess movement technique. In this workflow, the pose-estimation model provides the landmarks, while additional application logic interprets those coordinates to support exercise analysis.
