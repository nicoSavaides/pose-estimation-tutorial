Modern Pose-Estimation Systems

Listen to Page Overview

Human pose estimation can be implemented with different model architectures and landmark definitions. This tutorial looks at MediaPipe / BlazePose, Ultralytics YOLO Pose, and OpenPose as representative systems that show how pose estimation is approached in practice.

MediaPipe / BlazePose

BlazePose GHUM Holistic is a lightweight neural-network pipeline designed for real-time, on-device 3D human landmark and pose estimation from RGB imagery.[2]

These features are useful for fitness tracking and similar applications because the system is designed for live interaction without expensive external hardware. It produces a compact set of body landmarks that can describe movement continuously over time.

MediaPipe’s pose landmark representation includes 33 body landmarks, covering the shoulders, elbows, wrists, hips, knees, ankles, heels, and foot landmarks.[2]

Ultralytics YOLO Pose

YOLO Pose extends the YOLO ecosystem to pose estimation and produces detected instances together with body keypoints.[3]

The standard human pose models use the COCO keypoint representation, which contains 17 landmarks including the nose, shoulders, elbows, wrists, hips, knees, and ankles.

Prediction results include keypoint coordinates in pixel and normalized space, along with visibility or confidence information when it is available.[3]

OpenPose

OpenPose is an influential real-time multi-person 2D pose-estimation approach.[4]

In a simple technical description, its bottom-up strategy detects body-part candidates and uses Part Affinity Fields (PAFs) to encode associations among body parts. Instead of processing each person independently, the method infers how detected parts belong together and then assembles them into full human pose structures.

Multi-person scenes add a challenge: the system must decide which detected knee, elbow, wrist, and other keypoint belongs to which person.

Different Approaches, Same Goal

All three systems represent body position, but they differ in architecture, landmark definitions, dimensionality, multi-person handling, and deployment priorities. BlazePose emphasizes lightweight, on-device estimation for real-time applications; YOLO Pose fits naturally into a detection-oriented pipeline and exposes keypoint coordinates with associated metadata; OpenPose is a widely discussed multi-person approach that assembles bodies from detected body-part candidates and associations.

The best choice depends on the application. For exercise analysis, the next chapter compares how these approaches support real-time tracking, movement interpretation, and practical deployment choices.
