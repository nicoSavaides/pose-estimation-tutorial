Calculating a Joint Angle

The knee is treated as the vertex of an angle formed by the hip, knee, and ankle landmarks. Let A = hip, B = knee, and C = ankle.

θ = arccos(((A − B) · (C − B)) / (||A − B|| ||C − B||))

The vectors from the knee toward the hip and ankle are compared with the dot product to estimate the angle between them.

From Angle to Movement State

A relatively straight leg produces a larger knee angle, while bending into a squat decreases that angle. An application can therefore define movement states such as Standing → Lowering/Bottom → Standing and count a repetition when a full cycle is complete. Pose-estimation skeleton data has also been studied as input for vision-based exercise repetition-counting methods.[5]

Any numerical angle thresholds would need to be chosen and validated for the specific application, camera setup, and exercise. There is no universal “correct squat” threshold that applies in every case.

Example Algorithm

import numpy as np

def calculate_angle(a, b, c):
    a = np.array(a)
    b = np.array(b)
    c = np.array(c)
    ba = a - b
    bc = c - b
    cosine_angle = np.dot(ba, bc) / (
        np.linalg.norm(ba) * np.linalg.norm(bc)
    )
    cosine_angle = np.clip(cosine_angle, -1.0, 1.0)
    angle = np.arccos(cosine_angle)
    return np.degrees(angle)

The function first converts landmark coordinates into vectors by subtracting the knee position from the hip and ankle positions. It then computes the dot product of the two vectors, normalizes by their magnitudes, and applies arccos to recover the angle between them. Finally, the result is converted from radians to degrees. The np.clip step prevents small floating-point errors from pushing the cosine value outside the valid range for arccos.

Pose Estimation Is Only the First Step

Pose estimation supplies the landmark coordinates; joint-angle calculation, movement-state logic, repetition counting, and form-analysis rules are downstream application logic.[2]
